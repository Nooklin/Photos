# Nooklin Photos 1.3.4

## What is new

### Albums
- The + button always opens a menu: New Album in the album overview, New Folder and Add Item in an album or folder (New Folder is left out at the deepest level). New Folder moved there from the more menu.
- Adding items to an album: type a name for a new album, or choose Choose existing album. That opens a page with your albums where you can open albums and folders, search by name and place the items with Place here. This also works in the Hidden Section.

### Hidden Section
- Search by file name in the Hidden library.
- Timeline bar with years and months in the Hidden library, like the main library.
- Merge albums in the Hidden Section, and duplicate an item.
- Duplicates page to find and clean up similar photos.
- Video thumbnails are no longer black.
- The Hidden info sheet shows the original file name. Search also matches the internal name.
- Editing a photo in the Hidden Section saves a copy next to the original, like in the library.

### Library
- Search filters: combine the search term with Photos, Videos, Favorites and a year. Also in the Hidden Section.
- On this day: photos from this date in earlier years. Also in the Hidden Section.
